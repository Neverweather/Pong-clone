# Pong-clone
A clone of the first videogame ever, pong
Thanks to codeman38 for making the font (I don't know him personally I found it online)
# How to install
You need to install pygame-ce and pygame_gui with pip like this

How to install pygame_gui (Note, this will also install pygame-ce which is normal and what this pong clone uses):

``bash
pip install pygame_gui
```

To clone my repository: 

```bash
git clone https://github.com/Neverweather/Pong-clone
```
And to run it:
```bash
python3 src/pong.py
``
Now bring a compagnion and have fun!
